Firmware update
Installs the firmware published with this page (web/firmware/). The first time, Android asks to pair: enter the passkey (123456 unless OTA_PASSKEY was changed). Keep the screen on and stay close; it takes about 3 minutes. Update over Wi-Fi has the board download the same image over the Wi-Fi network set up below, which is much quicker; the phone only has to stay connected.
Wi-Fi
For updating over Wi-Fi. The board keeps the network and password in its own memory, through updates and USB uploads, and switches Wi-Fi on only while scanning or updating.
    The first time, Android asks to pair (same passkey as the update). The password travels over the encrypted BLE link. Only 2.4 GHz networks work.
